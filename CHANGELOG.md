# Changelog

## Latest
- The toolbar no longer opens just because the cursor is over a site header: push the cursor against the top edge. Moving down, Back or Down on the remote closes it.
- Ad and popup blocking with a per-site pause and an updatable filter list.
- Continue watching: resume prompt and a start-page row.
- Phone media page (play/pause, seek, speed, fullscreen) and TV media keys.
- Sync now also carries settings and the continue-watching list.

## 2.x
- Browser for TV with mouse and button modes, Desktop/Tablet/Phone site versions, bookmarks, history, downloads and files.
- Phone as a remote: QR pairing, trackpad, D-pad mode, text field with Go, scroll strip, mute and volume.
- Video fullscreen prompt.
- Firebase sync with an ID per device: merge or replace.
- In-app updates from GitHub releases.
- Adjustable screen-edge margin (overscan) in steps of 0.1% with corner-arc guide.
- English and Georgian; more languages by adding a `values-XX/strings.xml` file.
