# ენის დამატება

[English](TRANSLATING.md) · **ქართული**

აპის ყველა ტექსტი ცალკე ენის ფაილებშია, ამიტომ ახალი ენის დასამატებლად კოდის შეცვლა საჭირო არ არის.

1. დააკოპირეთ `app/src/main/res/values/strings.xml` ფაილი როგორც `app/src/main/res/values-XX/strings.xml`, სადაც `XX` ენის კოდია (მაგალითად `values-de`, `values-es`, `values-fr`).
2. თარგმნეთ ტექსტი `<string>` ტეგებს შორის. `name` ატრიბუტები არ შეცვალოთ და შეინარჩუნეთ `%s`, `%d`, `%1$d` ნიშნები. ახალი ხაზისთვის გამოიყენეთ `\n`, აპოსტროფისთვის `\'`.
3. `lang_code`-ში ჩაწერეთ თქვენი ენის კოდი (ის ტელეფონის პულტის გვერდის `lang`-ია).
4. `remote_`-ით დაწყებული სტრიქონები ტელეფონის პულტის გვერდის ტექსტებია. ისინი იმავე ფაილშია.
5. აპი ტელევიზორის ენას თავისით ირჩევს, თუ ის არ მოიძებნა, ინგლისურს იყენებს.

დოკუმენტაციისთვის დააკოპირეთ `README.md` როგორც `README.XX.md`, `docs/SETUP.md` როგორც `docs/SETUP.XX.md`, თარგმნეთ და თითოეული ფაილის ზედა ხაზში ენის ბმული დაამატეთ. თქვენი ენის სქრინები შეგიძლიათ `docs/images/XX/`-ში ჩადოთ (არასავალდებულო).
